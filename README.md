# SiftMail 📬⚡

AI-Powered Email Intelligence & Action Management Workspace. Sift through communication chaos, extract actionable tasks, auto-generate contextual replies, and gain productivity analytics.

## Features ✨
- **🧠 AI Email Sifter**: Automatic urgency scoring, sentiment analysis, and key takeaways.
- **✅ Action Item Extraction**: Automatically converts email commitments into tracked tasks.
- **✍️ Smart Reply Generator**: Drafts responses in multiple tones (Professional, Urgent, Friendly, Concise).
- **📊 Inbox Analytics**: Visualize email load, urgency distribution, and time saved by AI.

## Project Structure
```
SiftMail/
├── backend/    # Node.js + Express + TypeScript API server
├── frontend/   # React + Vite + TypeScript web interface
└── README.md
```

## Quick Start 🚀

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
