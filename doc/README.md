## ⚡ Quick Architecture Highlights
- **AI Dual-Engine**: Google Gemini 2.5 Flash with zero-downtime Heuristic NLP fallback.
- **Full-Stack TypeScript**: Express.js REST API + Vite React 18 frontend with dark glassmorphic styling.
- **Autonomous Task Extraction**: Direct email-to-Kanban conversion with zero manual overhead.
