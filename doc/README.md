# 📚 SiftMail Documentation Suite

Welcome to the official technical and product documentation for **SiftMail** — an AI-powered Smart Email Sorter that intelligently organizes, categorizes, prioritizes, and summarizes emails using Machine Learning and NLP.

---

## 🛠️ Technology Stack
- **Backend**: Python 3.11+ • FastAPI • Uvicorn • Pydantic • Google Gemini 2.5 Flash SDK (`google-genai`)
- **Database**: PostgreSQL 16 • SQLAlchemy 2.0 (Async) • Alembic • asyncpg
- **Frontend**: Pure React 18 • Vite • Vanilla CSS (Glassmorphism & CSS Custom Properties)
